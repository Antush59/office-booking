# Office Booking

Учебное REST-приложение для бронирования переговорных комнат в офисе.

Пользователь может:
- посмотреть список переговорных комнат с характеристиками;
- посмотреть свободные 15-минутные слоты комнаты на дату;
- посмотреть свободные комнаты на заданный интервал даты;
- создать бронь (с проверкой пересечений);
- отменить бронь.

## Запуск

### 1. Поднять базу данных

```bash
docker compose up -d
```

Postgres поднимается на порту **5433** (БД `office_booking`, пользователь `office`).

### 2. Запустить приложение

```bash
mvn spring-boot:run
```

Приложение стартует на **http://localhost:8081**. При старте Liquibase применяет миграции (таблицы `rooms`, `bookings`), а сидер добавляет 3 комнаты.

## REST API

Базовый адрес: `http://localhost:8081`

| Метод | Путь | Описание |
|-------|------|----------|
| GET | `/rooms` | Список всех комнат |
| GET | `/rooms/{id}/free-slots?date=YYYY-MM-DD` | Свободные 15-мин слоты комнаты на дату |
| GET | `/rooms/free?date=YYYY-MM-DD&start=HH:mm&end=HH:mm` | Свободные комнаты на интервал |
| POST | `/bookings` | Создать бронь |
| DELETE | `/bookings/{id}` | Отменить бронь (soft-delete) |

### Пример создания брони

```http
POST /bookings
Content-Type: application/json

{
  "roomId": 1,
  "userName": "Антон",
  "startAt": "2026-10-13T10:00:00",
  "endAt": "2026-10-13T11:00:00"
}
```

Коды ответов:

| Код | Когда |
|-----|-------|
| 200 | успешный GET / DELETE |
| 201 | бронь создана |
| 400 | неверные входные данные (не 15-мин граница, вне 08:00–19:00, конец ≤ начала) |
| 404 | комната или бронь не найдена |
| 409 | пересечение с существующей бронью (в теле — имя и интервал конфликта) |

## Бизнес-правила

- Рабочий день: **08:00–19:00**.
- Минимальный шаг брони: **15 минут** (границы `:00`, `:15`, `:30`, `:45`).
- Бронь всегда в пределах одного дня, интервал полуоткрытый `[start, end)`.
- Отмена — **soft-delete**: бронь переводится в статус `CANCELLED`, а не удаляется.

## Тесты

```bash
mvn test
```

Интеграционные тесты запускаются поверх временного PostgreSQL-контейнера (Testcontainers), который создаётся на время прогона и удаляется автоматически.
