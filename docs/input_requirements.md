# Учебное приложение для бронирования переговрных комнат в офисе

## Технический стек

Java 17, Maven, SpringBoot 2.7, база данных в Docker(Postgres), TestNG, LogBack, синхронные REST запросы, Liquibase

## Ограничения

без UI, без сохранения данных в БД между сессиями, без авторизации, без ролевой модели.

## Функционал

Пользователь может посмотреть свободные переговорки, Внести бронирование на дату и время, посмотреть переговорки в
указанное время и дату, можно отменить бронь
